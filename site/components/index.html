Components

Every component is a plain class on semantic HTML: .nb-btn, .nb-card… Modifiers use--name, parts use __part. Each page lists anatomy, modifiers, accessibility needs and the tokens to override.

Layout

  • Container — Centers content with a max inline size and fluid gutters.
  • Stack — Vertical flow with consistent gaps between children.
  • Cluster — Inline group that wraps — tags, buttons, toolbars.
  • Grid — Auto-fitting responsive grid without breakpoints.
  • Sidebar — Two-pane layout; the sidebar wraps below content when space runs out.
  • Switcher — Row of equal children that switches to a column below a container threshold.
  • Center — Horizontally centered measure for readable text.
  • Cover — Full-height region with a vertically centered principal element.
  • Frame — Aspect-ratio box that crops media to fit.

Overlay

  • Accordion — Disclosure list built on <details>/<summary>. A shared name attribute makes items exclusive; height animates where ::details-content is supported.
  • Modal — Dialog built on native <dialog>: focus trapping, Esc to close and inert background come from the platform. Open with dialog.showModal() or the command/commandfor attributes.

Feedback

  • Alert — Inline message communicating status, with optional title, actions and dismiss button.

Content

  • Badge — Small status or count label.
  • Chip — Compact interactive token: filters, selections and removable tags.

Actions

  • Button — Triggers an action. Works on <button> and on <a> for navigation styled as a button.
  • Button group — Joins related buttons into one segmented control.

Data

  • Card — Groups related content and actions on a raised surface.
  • Table — Data table with tabular numbers, optional stripes, hover rows and a scrollable wrapper.

Forms

  • Checkbox & radio — Native checkbox or radio wrapped in its label, sized to meet the 24px target minimum.
  • Field — Label, control, hint and error message laid out consistently.
  • Input — Text input and textarea with hover, focus, invalid, disabled and read-only states.
  • Select — Native <select> with consistent styling; the wrapper draws the chevron.
  • Switch — On/off toggle built on a native checkbox with role=switch.

Navigation

  • Navbar — Site header with brand, primary navigation and actions; adapts to its container width without JS.
  • Tabs — CSS-only tabs driven by a native radio group (up to 8 tabs); enhanced to ARIA tabs by @newbrush/js.
