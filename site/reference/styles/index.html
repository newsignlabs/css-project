Design styles

Put a style class on <body> (or any element, as an island) and every component inside takes that look: class="neon", class="nb-neon" or data-nb-style="neon".class="style-default" resets a subtree. Styles compose with the light, dark and contrast themes.

Cyber

Cyberpunk HUD: notched corners, monospace labels and scanlines.

  • Classes: .cyber, .nb-cyber
  • Preferred scheme: dark · density: compact
  • Effects: notched-corners, mono-type, uppercase-labels, scanlines, glitch-hover
  • Token overrides: 16
Badge

G-morph

Glassmorphism: translucent surfaces, backdrop blur and soft light edges.

  • Classes: .g-morph, .nb-g-morph
  • Preferred scheme: auto · density: default
  • Effects: backdrop-blur, translucent-surfaces, ambient-background, light-edge
  • Token overrides: 9
Badge

Minimal

Quiet and editorial: hairline borders, no shadows, small radii and airy spacing.

  • Classes: .minimal, .nb-minimal
  • Preferred scheme: auto · density: airy
  • Effects: no-shadows, hairline-borders, small-radius, airy-spacing
  • Token overrides: 10
Badge

N-morph

Neumorphism: soft, extruded surfaces lit by paired light and dark shadows.

  • Classes: .n-morph, .nb-n-morph, .neumorph
  • Preferred scheme: light · density: default
  • Effects: extruded-surfaces, soft-shadow-pair, inset-pressed-states, large-radius
  • Token overrides: 8
Badge

Neon

Glowing accents and outlines on deep, near-black surfaces.

  • Classes: .neon, .nb-neon
  • Preferred scheme: dark · density: default
  • Effects: glow, outlined-controls, glow-focus-ring, text-glow, near-black-surfaces
  • Token overrides: 11
Badge

Pixelate

8-bit: square corners, stepped borders, a 4 px grid and pixel type.

  • Classes: .pixelate, .nb-pixelate, .pixel
  • Preferred scheme: auto · density: grid-4
  • Effects: square-corners, stepped-borders, steps-motion, pixelated-images, pixel-headings
  • Fonts (opt-in): pixelify-sans
  • Token overrides: 12
Badge
