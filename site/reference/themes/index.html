Themes & variants

Themes

Without an attribute, newBrush follows the system (prefers-color-scheme, plusprefers-contrast: more). Set data-nb-theme on any element to force a theme for that subtree; this site sets it on <html> from the theme picker.

ThemeAttributeColor schemeExtends
lightdata-nb-theme="light"light—
darkdata-nb-theme="dark"dark—
contrastdata-nb-theme="contrast"lightlight

Variants

Prefix a utility with a variant, e.g. hover:bg-accent or md:dark:p-8. Variants compose left to right.
