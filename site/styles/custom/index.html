Custom styles

A custom style works exactly like a built-in one: one class re-skins every component, it composes with every theme, and it can be an island on part of a page.

Checks you get for free

Section titled “Checks you get for free”
  • Every colour that resolves at build time is contrast-checked against the semantic pairs. Set contrast: { onFail: "error" } to fail the build on a miss.
  • The high-contrast theme, prefers-contrast: more and forced colors restore every colour your style changes.
  • npx nb style list shows the built-in and custom styles in your build.
  • npx nb doctor warns about several styles on one element, unknown data-nb-style values, and style names that clash with utilities.
