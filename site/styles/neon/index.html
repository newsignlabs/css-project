Neon

Glowing accents and outlines on deep, near-black surfaces.

Personality: neon, glow, synthwave, night, vibrant. Effects: glow, outlined controls, glow focus ring, text glow, near black surfaces.

Use it

Each line above does the same thing. Put it on any element instead of <body> to style just that part of the page. With a build step, neon: utilities apply only inside this style, for example neon:p-8.

Recipes

Beyond tokens, the style adds these touches (all written with tokens, inside the nb.styles layer):

  • nb-card: Accent edge with a soft outer glow
  • nb-btn--primary: Outlined in the accent colour, glowing
  • focus: Glow around the focus outline (the outline stays)
  • h1-h3: Text glow in the dark scheme

Accessibility

  • Dark unless a theme is set explicitly; data-nb-theme="light" gives the light variant
  • Glows are decoration only: removed under forced colors, the contrast theme and prefers-contrast: more
  • The focus outline is kept; the glow is added around it
  • The high-contrast theme, prefers-contrast: more and forced colors restore every colour the style changes, so contrast never depends on the style.

Pairs well with

  • Designed dark-first: without a theme attribute it renders dark, even when the system is light. Set data-nb-theme="light" for its light variant.
  • Default spacing.
  • Your brand colours: the style is built on the same tokens, so brand, accent and neutral seeds (seetheming) carry through.
