CDN

newBrush is plain CSS, so one <link> is enough to use every component and theme. No build step or JavaScript is needed.

Testing and prototypes

Section titled “Testing and prototypes”

Pin the major version, so you get fixes without breaking changes:

newbrush-full.min.css adds a curated set of utility classes on top, which is handy while prototyping. In production, generate only the utilities you use (see bundlers and frameworks).

Which file

Section titled “Which file”
File Contents
newbrush-core.min.css Reset, tokens, themes, base styles and layout primitives
newbrush.min.css Core, all components and the design styles
newbrush-full.min.css newbrush.min.css plus the curated utility preset
components/<name>.min.css One component, to add after core (for example components/button.min.css)
themes/<name>.css A theme on its own: light, dark or contrast
styles/<name>.css One design style on its own, such as styles/neon.css
manifest.json Machine-readable catalogue of tokens, utilities, components and styles

Every file has a .min.css version and a source map.
