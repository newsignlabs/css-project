Getting started

newBrush is plain CSS, so components and themes work without a build step. Add a build step only if you want utility classes generated from your markup.

1. Add the stylesheet

Section titled “1. Add the stylesheet”
  • CDN
  • npm

For prototyping, newbrush-full.min.css adds a curated set of utilities as well.
File Contents
newbrush.css Reset, tokens, themes, all components and the design styles
newbrush-core.css Reset, tokens, themes and base styles only
newbrush-full.css newbrush.css plus the curated utility preset

2. Use components

Section titled “2. Use components”

Dark mode follows the operating system. To force a theme on the page or on any part of it, set data-nb-theme="light", "dark" or "contrast". See themes and variants.

3. Generate utilities (optional)

Section titled “3. Generate utilities (optional)”

Install the CLI and a bundler plugin. Then only the utility classes you use end up in your CSS.

  • Vite
  • PostCSS
  • CLI

4. Brand it

Section titled “4. Brand it”

npx nb contrast checks that every text and surface pair meets WCAG AA.
