Architecture

One source of truth — design tokens — flows through the build into the stylesheet, the utility engine and a machine-readable manifest that powers docs, editor types and the MCP server.

1 · Design tokens

251 tokens in W3C DTCG JSON: OKLCH palette, fluid type & space, radius, elevation, motion. Tiered primitive → semantic → component.

↓

2 · Style Dictionary

Compiles tokens to layered CSS custom properties with light, dark and high-contrast themes, plus JS/TS, JSON and Figma variables.

↓

3 · Components + Lightning CSS

Hand-written native CSS (nesting, :has(), container queries, logical properties) for 16 components, bundled, lowered and minified.

↓

4 · Utility engine

137 families generate only the classes you use (JIT) from the same tokens; arbitrary values are validated.

↓

5 · manifest.json

Every token, component, utility and variant described as JSON — read by docs, editor types and AI agents.

Every rule lives in an ordered layer, so your own CSS always wins without !important.

Components

Each component is native HTML + CSS — dialogs use <dialog>, accordions <details>, tabs a radio group — so they work without JavaScript and pass axe accessibility checks in light and dark, at three widths and in right-to-left layouts.
